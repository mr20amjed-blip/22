# WebKitty Host — Amjad Thamer

واجهة عربية/إنجليزية تجريبية لمضيف PS4، بخلفية مستوحاة من Assassin's Creed Valhalla.

## التشغيل
افتح `index.html` في المتصفح أو انشر المجلد على GitHub Pages.

## الحالة
الأزرار حالياً توضيحية فقط؛ لا تشغّل جلبريك ولا تثبّت ملفات PKG. لا يوجد تأكيد لدعم أي إصدار Firmware.

## الحقوق
هذه الحزمة واجهة مستقلة ولا تحتوي نسخة كود WebKitty الأصلية. عند دمج أو توزيع كود WebKitty، احتفظ بإشعارات حقوق النشر والترخيص الأصلي، والتزم بـ AGPL-3.0-or-later. المشروع الأصلي: https://github.com/ArabPixel/WebKitty
